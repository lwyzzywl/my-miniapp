#  行知溯光————社会实践成果展示

> 这是一个基于微信小程序原生框架开发的社会实践成果展示“数字移动展厅”。本项目旨在将“行知溯光”团队跨越南京、淮安、梅州、重庆、杭州等地的线下调研成果，转化为可互动、可下载、可传播的全校性数字平台。

##  核心功能模块
*   ** 星火起航 (动态打卡地图)**
    支持多城市（南京、淮安、梅州等）横向轮播地图。内嵌基于相对坐标定位的红点标记动效，并集成了全校“星火接力”实时滚动计数器。
*   ** 寻光纪实 (多媒体时空日志)**
    采用“一级城市-二级学校”双层级联 Tabs 导航机制。无缝内嵌沉浸式 Vlog 视频播放器、可折叠的时间轴图文访谈录，以及支持原生 `wx.previewImage` 高清预览的前线图集。
*   ** 成果行囊 (零门槛资源站)**
    以列表形式集中分发成套实践成果（主题团课 PPT、完整讲稿）。首创“云盘链接+一键复制提取码”的交互方案，优雅绕过小程序原生文件下载限制。
*   ** 星火相传 (全校接力社区)**
    全校师生专属互动留言板。严格遵循微信最新隐私规范接入 `chooseAvatar` 与 `type="nickname"` 组件，支持用户点亮虚拟火种并发布带真实身份的感悟。

##  技术栈

| 模块 | 技术与方案 |
| :--- | :--- |
| **前端架构** | 微信小程序原生 (WXML, WXSS, Vanilla JS, JSON) |
| **设备适配** | 纯 `rpx` 响应式流式布局，动态 `wx.getWindowInfo` 适配刘海屏与自定义导航栏状态栏 |
| **媒体托管** | 剥离本地大文件，全面支持微信云开发 (CloudBase) 或第三方 HTTPS 纯净图床直链接入 |
| **状态管理** | 基于微信原生 `Storage` 缓存机制，实现跨页面状态保持与用户数据长效驻留 |

##  快速启动
1. **环境准备**
   下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. **导入项目**
   克隆本项目到本地，在微信开发者工具中点击“导入项目”，选择项目根目录。
3. **AppID 配置**
   在导入界面填入你申请的微信小程序 AppID（测试阶段可选择“测试号”，正式发布需个人/企业主体 AppID）。
4. **数据替换与云端部署**
   项目中包含大量媒体资源配置点。请全局搜索 `*.js` 配置文件中的 `urls` 与 `video` 字段，将其替换为你们团队实际的云端存储 HTTPS 直链。
